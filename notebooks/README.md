# Notebooks

Les notebooks des séances, à copier dans le dossier `exercices/` du dépôt
de votre binôme, puis à compléter et à pousser avec vos réponses.

## Séance 3 · Simuler les lois binomiale et de Poisson

Dans le terminal de votre codespace, à la racine de votre dépôt, collez :

```bash
curl -fsSL -o exercices/seance-03-simulation-binomiale-poisson.ipynb https://raw.githubusercontent.com/Ad-C/mth101/main/notebooks/seance-03-simulation-binomiale-poisson.ipynb
```

Ouvrez ensuite `exercices/seance-03-simulation-binomiale-poisson.ipynb`,
puis **Exécuter tout**. À la fin : commit et push.

Si Codespaces ne répond pas :
[ouvrir le notebook dans Google Colab](https://colab.research.google.com/github/Ad-C/mth101/blob/main/notebooks/seance-03-simulation-binomiale-poisson.ipynb)
(compte Google requis ; enregistrez une copie avant de le modifier).
